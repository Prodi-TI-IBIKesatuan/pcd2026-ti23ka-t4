## Anotasi

Transkrip teks lengkap dan isian tanggal serta total.

Simpan sebagai `anotasi.csv` di folder Drive, satu baris per citra (atau per pasangan), dengan kolom persis seperti [format_anotasi.csv](format_anotasi.csv). Baris contoh di berkas itu fiktif.

## Etika dan privasi

Sensor nomor kartu, nama, dan nomor telepon pada struk sebelum diunggah ke data/sample. Jangan menulis NIM, nama orang lain, atau data pribadi lain di repo ini.
